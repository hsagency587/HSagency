# La mia routine

Web app statica e mobile-first. Non richiede database, account o installazione di dipendenze.

## Pubblicazione su HS Agency

1. Carica l'intera cartella `routine` nella cartella pubblica del sito, senza rinominare i file interni.
2. Mantieni la cartella `assets` del sito nella posizione attuale: l'app usa il logo e i font già presenti.
3. Apri `https://tuodominio.it/routine/`.

Per l'uso offline e l'aggiunta alla schermata Home è necessario pubblicare il sito in HTTPS.

## Dati personali

Le spunte e la cronologia vengono salvate nel `localStorage` del browser. Restano sul singolo
dispositivo e non vengono sincronizzate. Cancellare i dati del browser elimina anche la cronologia
della routine.
